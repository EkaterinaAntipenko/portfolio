# Страница проекта по макету

Ветка: `test` · Макет: Figma, node `625-225`

---

## 1. Что изменилось

Страница `/project/:id` переверстана по макету. Раскладка стала обратной прежней: **слева карточка с информацией, справа лента изображений**.

| Было | Стало |
|---|---|
| Слева картинки, справа информация | Слева карточка, справа презентация |
| Тёмная тема портфолио | Фон `#111`, карточки `#242424` |
| Кнопка «← К проектам» | Белая пилюля «К карте сайта» |
| Список ссылок в рамке | Светлая полоса «Процесс создания» с плюсом |

---

## 2. Раскладка

```
К карте сайта                                    ← белая пилюля, radius 12

┌──────────────┐  ┌────────────────────────────┐
│ Заголовок    │  │                            │
│ Описание     │  │   изображения проекта      │
│ Теги         │  │   (вертикальная лента)     │
│              │  │                            │
│ ────────────  │  │                            │
│ Процесс   +  │  │                            │
└──────────────┘  └────────────────────────────┘
   530fr                    1080fr
```

Левая карточка липкая (`sticky`): при прокрутке изображений информация остаётся на экране. Колонки заданы пропорцией `530fr / 1080fr` — как в макете, но тянутся под ширину экрана. На экранах уже 992px колонки складываются в одну.

## 3. Значения из макета

| Элемент | Значение |
|---|---|
| Фон страницы | `#111111` |
| Карточка и рамка галереи | `#242424`, скругление `30px` |
| Отступы карточки | `43px 35px` |
| Отступы галереи | `34px 37px`, изображения `28px` |
| Заголовок | `45.4px`, по центру, трекинг `-0.03em` |
| Описание | `18px`, `rgba(255,255,255,0.4)`, ширина `403px` |
| Теги | `#3b3b3b`, текст `rgba(255,255,255,0.6)`, скругление `95px`, паддинг `8px 26px` |
| Кнопка «К карте сайта» | белая, `10px 30px`, скругление `12px` |
| Полоса списка | `#d9d9d9`, высота `63px`, скругление `15px` |
| Межстрочный | `1.416` |

Размеры заголовка и кнопок заданы через `clamp()`: на ширине макета (1728px) они совпадают с оригиналом, на узких экранах уменьшаются.

## 4. Ассеты

Из макета выгружены и сохранены в репозиторий:

```
src/assets/glow.svg   # оранжевое свечение в фоне (#FD894A, 10%)
src/assets/plus.svg   # плюс в полосе «Процесс создания»
```

Иконки не рисовались вручную — это точные файлы из Figma. Плюс поворачивается на 45° при раскрытии списка.

## 5. Данные

Вёрстка осталась полностью на данных из базы: заголовок, описание, теги, изображения и пункты выпадающего списка приходят из таблиц `projects`, `project_images` и `project_links` и правятся в админке.

Заголовок полосы — «Процесс создания» из макета, внутри неё выводятся пункты из `project_links`.

## 6. Проверено

- значения в браузере совпадают с макетом: фон `rgb(17,17,17)`, карточка `rgb(36,36,36)` / `30px`, теги `rgb(59,59,59)` / `95px`, полоса `rgb(217,217,217)` / `63px` / `15px`, пропорция колонок `0.49` (в макете `530/1080`);
- свечение и плюс подгружаются, плюс поворачивается при раскрытии;
- на 375px раскладка в одну колонку, горизонтальной прокрутки нет;
- `yarn build` и `yarn lint` — без ошибок.

## 7. Замечание по шрифту

В макете используется **Everett**, в проекте подключён **Bounded** (файлы шрифта в репозитории отсутствуют — Vite предупреждает об этом при сборке). Сейчас страница использует системный шрифт проекта. Когда появятся файлы нужного шрифта, достаточно положить их в `src/fonts` и объявить в `stylesheets/fonts.scss` — размеры и трекинг уже выставлены по макету.
